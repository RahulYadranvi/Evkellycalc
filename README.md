EV Kelly Calculator
An institutional-grade quantitative finance calculator designed to determine optimal position sizing, track algorithmic trade edges, and calculate Risk of Ruin utilizing the Kelly Criterion.

 Engine Features
- **Expected Value (EV) Modeling:** Strict calculation of positive/negative expectancy based on win probability and execution friction.
- **Fractional Kelly Allocations:** Mathematical computation of Full, Half, and Quarter Kelly fractions.
- **Risk of Ruin Computation:** Probability modeling for consecutive drawdowns based on fractional allocations.
- **Geometric Growth Projection:** 100-event Monte Carlo visualization mapping compounding variance.

 Architecture
Built on a high-performance Astro static engine with vanilla JavaScript execution and Chart.js for data visualization. Locked down with edge-level CSP and anti-clickjacking headers.
